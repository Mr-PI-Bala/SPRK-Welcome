# SPRK-Welcome

Public doorway for SPRK students to learn how to join, request access, and start using SPRK repositories.

SPRK is the student-focused Coding Club in the AURAVYBE context. This repository is the public front door. It explains the student path before a student receives access to private working repositories such as `SPRK-Hello-Ursina`.

## Start Here

- Official doorway: `https://github.com/Mr-PI-Bala/SPRK-Welcome`
- First working project: `https://github.com/Mr-PI-Bala/SPRK-Hello-Ursina`
- [Create or convert a SPRK GitHub account](docs/USER_GUIDE.md#create-or-convert-a-sprk-github-account)
- [Request access to a working repository](docs/USER_GUIDE.md#request-access-to-a-working-repository)
- [Use Codespaces](docs/USER_GUIDE.md#use-codespaces)
- [Create your branch](docs/USER_GUIDE.md#create-your-branch)

If a working repository is private, request access through the process described in [docs/USER_GUIDE.md](docs/USER_GUIDE.md).

## SPRK Path

```text
Create or convert a GitHub account
  |
  v
Read SPRK-Welcome
  |
  v
Request access to a working repository
  |
  v
Open Codespaces
  |
  v
Run the safe project check
  |
  v
Create your branch
  |
  v
Make change, commit, push, and open a Pull Request
```
