# SPRK-Welcome
Public doorway for SPRK students to learn how to join, request access, and start using SPRK repositories.

SPRK is the student-focused Coding Club in the AURAVYBE context. Start here, then request access to the project repository you want to try.

## Quick Start Guide
1. Create or convert your SPRK GitHub account using the `FirstName-SPRK` username pattern.
2. Pick a repository from [Repository Request List](#repository-request-list).
3. Request access if the repository is private or if you cannot push your own branch.
4. Open Codespaces or the browser project preview for that repository.
5. Create your own branch, make a small change, push it, and open a Pull Request.
6. Optional: for group/multiplayer activities, use the [classroom network test guide](docs/SPRK_Classroom_Network_Test_Guide.md) before students join from phones, Chromebooks, or tablets.
